Overview

ATDAS (Automated Threat Detection and Alert System) is a machine learning-driven intelligence platform designed to detect, classify, and assess potential threats from visual sensor data.

The system leverages deep learning models for object detection and adversarial robustness evaluation while providing a containerized, reproducible deployment architecture suitable for edge or distributed environments.

ATDAS focuses on:

High-confidence target detection

Adversarial robustness evaluation

Threat scoring and alert generation

Modular, Docker-based deployment

This project simulates defense-relevant ISR (Intelligence, Surveillance, Reconnaissance) workflows using modern ML infrastructure.
